# Kanade Foods v4 — Mulund

Professional customer ordering UI inspired by familiar quick-commerce patterns:
- Location-first experience, restricted to Mulund
- Four categories: Fresh Cut Vegetables, Fresh Cut Fruits, Ready-to-Cook Mixes, Fresh Sprouts
- Search, category tabs, cart drawer, quantity controls
- Product card shows “1 added”, “2 added”, etc. after adding
- Cart displays 1kg instead of 1000g
- WhatsApp checkout uses 8104130330
- Mobile responsive
- Supplied Kanade Foods logo integrated

Deploy the folder to Vercel. `/` is the customer site and `/admin` is the existing admin demo.
